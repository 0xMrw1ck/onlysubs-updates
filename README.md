# onlysubs updates

This public repository is the **download and automatic-update channel** for the Windows onlysubs beta. It deliberately contains release assets and notes, not the application source code.

## Download safely

Use the latest release to download the Windows installer. Each release includes a `SHA256SUMS.txt` file so you can verify the installer before running it. The beta installer is currently unsigned; keep Windows Security enabled and do not download installers from mirrors or unsolicited messages.

## Automatic updates

onlysubs checks this repository for a newer version when the installed app starts. It asks before downloading, installs only after you close the app, and sends no video, transcript, or project data to GitHub. Update checks may disclose your IP address and normal connection information to GitHub.

## Support and security

The core editor is free. GitHub Sponsors for WickWorks is pending verification. Report a suspected security issue privately to `hello@wickworks.app`; do not post exploit details, private footage, passwords, or tokens in a public issue.
